## Intro

<a href = "https://maerzy.itch.io/clawsembly-line">Clawsembly Line</a> is a gamey installation I created during my studies. It is basically a claw machine with which one can build a character aka it's a Claw Machine - Character Creator mashup.

Players get three grabs per character, they need to grab features from a moving conveyor belt with their claw. These features are then dropped onto a blank avatar to customize it. One's latest creation can also be viewed and shared via a QR code. 

The whole project is designed as a installation where people create a character and over time a huge crowd of previous creations is displayed in the game world. A huge inspiration with the style and concept were Miis of course!
